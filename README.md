# 오이붕 턴제 배틀 · 개발용 분할판

이 프로젝트는 **2026-09-25 버그 수정 통합 HTML**을 그대로 분할한 버전입니다. 캐릭터 3명 엔트리, 화면, 밸런스, 전투 및 연결 관련 수정 사항을 다시 작성하거나 제거하지 않았습니다.

## 파일 구성

- `index.html`: 화면과 PeerJS CDN 참조
- `style.css`: 화면 스타일
- `js/data.js`, `js/engine.js`, `js/ai.js`, `js/audio.js`, `js/effects.js`, `js/app.js`: 기존 순서대로 불러오는 게임 코드
- `build_single.py`: 개발 파일에서 공유용 통합 HTML을 만드는 도구 (Python 표준 라이브러리만 사용)

## 실행과 배포

개발 중에는 이 폴더의 `index.html`을 엽니다. **`js` 폴더와 `style.css`를 같은 구조로 유지**하세요. 친구에게 배포할 때는 이 폴더에서 `python build_single.py`를 실행한 뒤 생성되는 `dist/oibung_battle_share.html`을 공유합니다. 통합 HTML을 직접 수정하지 말고 분할된 개발 파일을 고쳐 다시 빌드하세요.

이 버전의 NPC 게임 코드는 파일 안에 포함되어 있지만, 온라인 대전·관전에는 인터넷과 외부 PeerJS 라이브러리 및 연결 서비스가 필요합니다. 일부 모바일 파일 미리보기에서는 로컬 JS 파일 실행이 제한될 수 있으니 그때는 웹 호스팅 링크나 통합 HTML 배포본을 사용하세요.

빌드 후에는 NPC 대전, 2인 대전의 턴 교환·기절 교체, 관전 중 입장·퇴장, 모바일 브라우저 표시를 확인하세요. 이번 분할은 코드 내용 보존을 우선해 외부 CDN도 그대로 남겼습니다.
